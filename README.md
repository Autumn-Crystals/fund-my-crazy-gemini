# Gemini City Launch

Create a modern, highly polished, responsive landing page for a student innovation event called “FUND MY CRAZY IDEA”.
REFERENCE & DESIGN DIRECTION
Use https://fundmycrazy.com/ as the primary visual and structural inspiration.
Do NOT simply clone the website. Instead, take inspiration from its:
Google Gemini-inspired visual identity
Blue and yellow color palette
Large expressive typography
Playful illustrated city/technology visuals
Rounded cards
Soft shadows
Light blue grid backgrounds
Strong visual hierarchy
Clean modern spacing
Interactive theme cards
Large prize section
Simple 3-step participation flow
The attached reference screenshots should also influence the visual style.
The final website should feel like a Google/Gemini student innovation campaign: energetic, futuristic, playful, premium, youthful and trustworthy.
Primary colors:
Bright Google-style blue
Strong vibrant yellow
White
Small amounts of green/red only as supporting colors
Use yellow heavily for CTAs, highlights, badges and important numbers.
Use blue for major backgrounds, hero sections and visual blocks.
Avoid making it look like a generic corporate website.
CORE PURPOSE
This is NOT the actual submission platform.
The website is an event information and registration landing page.
A student should arrive from a WhatsApp/Instagram/message announcement and immediately understand:
What is Fund My Crazy Idea?
What do I have to do?
What are the six themes?
How does Gemini fit into the challenge?
When is the event?
What can I win?
How will I be judged?
How much does registration cost?
Where do I register?
The most important action on the entire website is:
REGISTER NOW
Every major section should eventually guide the user toward registration.
The registration button must open the provided Google Form.

FINAL DESIGN PRINCIPLE
The website should feel like:
Google Gemini × Student Innovation × Futuristic City × Crazy Ideas
It should NOT feel like:
A normal college registration form
A boring corporate event page
A generic SaaS landing page
An overly complicated competition dashboard
The participant should be able to understand the entire event within 30–60 seconds of scrolling.
The visual hierarchy should constantly lead toward:
UNDERSTAND → GET EXCITED → REGISTER
Most importantly, make REGISTER NOW the primary conversion action throughout the website.
Build the site as a polished production-quality landing page, not a wireframe or basic template.
